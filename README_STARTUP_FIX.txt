LED Screen Designer v20.27 — Windows STARTUP FIX

Исправлено:
1. Удалён молчаливый переход в МЦД при ошибке приветственного окна.
2. Добавлены отсутствовавшие imports sys и traceback.
3. Ошибка стартового окна теперь записывается в:
   %LOCALAPPDATA%\LED_Screen_Designer\startup_error.log
4. При ошибке показывается окно с типом и текстом исключения.
5. Приветственному окну назначается app.ico.
6. Сохранён предыдущий Tcl/Tk runtime fix.
7. GitHub Actions проверяет наличие startup selector до сборки.

Важно: если приветственное окно не сможет создаться, приложение теперь НЕ
продолжит работу в режиме МЦД автоматически.
